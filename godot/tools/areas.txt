# Which areas each file that isn't a script touches, for check.sh quick
# (PIX-353): a script names its own on an "## areas:" line under its
# class_name/extends. A line is the areas, a colon, then the files (globs from
# godot/); a changed file takes the areas of the first line that names it.
# "all" runs every flow, "none" no flow (the checks, GUT and the town's boot
# still run). +name adds boots (a name from flows.sh --boot --list, or a glob
# of them). all comes first: tools/flows.py is a tools/*.py, and it checks
# every flow. Two branches adding lines keep both on a merge (merge=union in
# .gitattributes); tools/test_areas.py refuses a glob named twice.
